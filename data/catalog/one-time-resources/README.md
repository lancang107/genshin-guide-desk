# 一次性资源库

跨版本的永久游戏内资源目录。每条记录描述一个可独立完成的一次性资源来源，包含奖励、耗时、前置依赖和核验状态。

## 目录结构

```
data/catalog/
  one-time-resources/
    regions.json              # 地区索引
    snezhnaya/                # 至冬国家下的挪德卡莱大区 (7.0)
      archon-quests.json      # 魔神任务
      world-quests.json       # 世界任务
      chest-routes.json       # 宝箱路线批次
      oculus-routes.json      # 神瞳路线
      achievements.json       # 成就组
      offerings.json          # 供奉系统
      domain-first-clears.json # 秘境首通
  evidence/
    snezhnaya-7.0.json        # 至冬 7.0 证据记录
```

## 奖励统计（至冬 > 挪德卡莱）

- 任务线直接原石：主线和已核验常驻任务合计 940 原石
- 相遇之缘：0 个（7 个相遇之缘来自另一条一条龙路线记录，不能与任务线直接相加）
- 宝箱、神瞳、供奉和一条龙路线：仍保持独立记录，避免重复统计

> 资源库的目录总数不是可直接相加的总收益。路线批次、任务奖励和供奉奖励可能覆盖同一段游玩过程，最终套餐汇总需要使用覆盖关系和完成粒度去重。
