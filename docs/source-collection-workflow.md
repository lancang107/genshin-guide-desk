# 信息拉取工作流

> 目标：每个原神版本更新时，稳定收集官方版本/卡池信息、攻略 UP 主新视频和可落地的数据草稿。

## 一、官方版本信息

官方信息只从三个渠道确认，按可信度排序：

| 优先级 | 渠道 | 用途 |
|--------|------|------|
| 1 | 原神官方网站公告 | 版本起止日期、卡池角色、武器池、活动时间 |
| 2 | 米游社原神官方公告 | 版本公告、活动详情、网页活动、兑换码 |
| 3 | B 站原神官方号动态 | 卡池宣发、活动提醒、兑换码提醒 |

### 产出文件

每次版本更新时生成：

| 文件 | 内容 |
|------|------|
| `data/versions/{version}/meta.json` | 版本号、上下半卡池、角色、武器、起止日期 |
| `docs/{version}-official-notes.md` | 官方公告摘录和来源链接 |

### 审核规则

1. 卡池信息必须至少由 1 个官方渠道确认。
2. 如果三个渠道信息冲突，以官方网站公告为准。
3. 下半卡池未公布时，允许 `meta.json` 中 phase 2 的 `characters` 和 `weaponBanner` 为空数组。
4. 所有日期使用 ISO 日期格式，具体时间写入 notes 或单独字段。

## 二、攻略 UP 主视频拉取

从 `data/creators.json` 读取 UP 主池，按 specialty 分类搜索。

### 原石来源

优先搜索：

| 类型 | UP 主 | 搜索关键词 |
|------|------|------------|
| 原石总览 | 你的影月月、冰糖小堃、莴苣某人 | `原神 {version} 原石 总计`、`{UP主} {version} 原石` |
| 地图探索 | 你的影月月、阿牛不能吃 | `原神 {version} 一条龙`、`原神 {version} 全宝箱` |
| 活动攻略 | 你的影月月、冰糖小堃、莴苣某人 | `原神 {version} 活动 攻略` |

### 角色养成

优先搜索：

| 类型 | UP 主 | 搜索关键词 |
|------|------|------------|
| 角色养成 | 卡特亚、贪欲九头蛇、莴苣某人、吟游诗人基德 | `{角色名} 养成 攻略` |
| 材料采集 | 阿牛不能吃、你的影月月 | `{角色名} 突破材料`、`{特产名} 采集路线` |
| 武器材料 | 卡特亚、贪欲九头蛇、普通材料路线 UP | `{专武名} 突破材料` |

### 产出文件

| 文件 | 内容 |
|------|------|
| `data/versions/{version}/primogems.json` | 原石来源和攻略链接 |
| `data/versions/{version}/characters/{character}/materials.json` | 角色材料和养成攻略链接 |
| `docs/{version}-content-status.md` | 本次搜集结果、待确认项 |

## 三、自动化脚本规划

后续脚本放在 `scripts/`：

| 脚本 | 作用 |
|------|------|
| `new-version-scaffold.js` | 创建新版本目录、复制套餐模板、生成空 meta |
| `fetch-official-news.js` | 拉取官网/米游社/B 站官方号的版本和卡池信息 |
| `search-guides.js` | 按 UP 主池和关键词搜索 B 站视频 |
| `generate-draft-data.js` | 将搜索结果写入草稿 JSON |
| `validate-data.js` | 校验 JSON 结构和引用关系 |

## 四、人工审核点

自动化只生成草稿，不直接覆盖正式数据。每次上线前人工确认：

1. 官方卡池信息是否准确。
2. 原石数值是否来自可靠视频或官方公告。
3. 攻略链接是否为高质量、时效正确的视频。
4. 角色材料中是否还有 `待确认` 字段。
5. 四个套餐的时间安排是否现实，尤其是上半卡池只剩几天时。
