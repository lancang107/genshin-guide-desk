# 养成材料分类表

> 本表列出角色养成的完整材料体系，含日轮换映射关系。攒石期间同步刷取，抽到后可直接突破。

| 大类 | 材料类型 | 树脂来源 | 日轮换 | 备注 |
|------|----------|----------|--------|------|
| 突破 | 地区特产 | 探索采集/种植 | 否 | 48h刷新，可种田 |
| 突破 | 普通 BOSS 掉落 | 40 树脂/次 | 否 | 无日轮换限制 |
| 突破 | 元素石系列 | BOSS掉落/合成 | 否 | 可通过合成台转换 |
| 突破 | 普通敌人掉落 | 大世界刷怪 | 否 | 无限制 |
| 天赋 | 天赋书系列 | 20 树脂/次 | **是** | 周一/三/五，周二/四/六，周日全开 |
| 天赋 | 周本掉落 | 60 树脂/次 | 否（周限3次） | 每周前3次半价 |
| 武器 | 武器突破材料 | 20 树脂/次 | **是** | 与天赋本共享轮换规则 |

## 二、日轮换详细映射

| 地区 | 天赋书系列 | 周一/周四/周日 | 周二/周五/周日 | 周三/周六/周日 |
|------|-----------|---------------|---------------|---------------|
| 蒙德 | 自由/抗争/诗文 | 自由 | 抗争 | 诗文 |
| 璃月 | 繁荣/勤劳/黄金 | 繁荣 | 勤劳 | 黄金 |

> 注：周日所有天赋书均可刷，但效率不如对应日刷（掉率相同但选择多时容易分散）。

### 2.2 武器突破材料轮换表

> 每个地区有一套武器材料系列，三组按日轮换（与天赋本同日但不共享秘境）。

| 地区 | 材料系列 | 周一/周四/周日 | 周二/周五/周日 | 周三/周六/周日 |

| 稻妻 | 远海/鸣神/今昔 | 远海系列 | 鸣神系列 | 今昔系列 |
| 须弥 | 绿洲/烈日/谵妄 | 绿洲系列 | 烈日系列 | 谵妄系列 |

> 注：以上材料名为系列简称，实际每组含 3 个品阶（2星/3星/4星/5星），通过合成台可升阶。

### 2.3 轮换规划原则

1. **先查角色需求**：确认目标角色需要哪个地区、哪一列的天赋书和武器材料
2. **对齐日期**：天赋本和武器本在同一天可以刷不同的列（如周一刷蒙德天赋"自由" + 璃月武器"雾海"），但只能同时刷一个秘境
3. **周日是万能日**：所有材料都开，但如果某天已错过，周日可以补
4. **周本不轮换**：周本材料不按日轮换，但每周只能打3个不同周本享受半价（30树脂），第4个起60树脂
5. **地脉/BOSS不轮换**：经验书、摩拉、普通BOSS掉落随时可刷

### 3.5 树脂总消耗估算

| 项目 | 估算树脂 |
|------|---------|
| 角色突破 BOSS | 1840 |
| 天赋全满 | 约 1380（含周本） |
| 武器突破 | 约 280 + 周本 |
| 经验书 | 约 1040 |
| 摩拉 | 约 1860 |
| **合计（不含圣遗物）** | **约 6400 树脂** |

> 6400 树脂 ≈ 213 天自然恢复（30 树脂/8 小时），或使用脆弱树脂加速。
> 这就是为什么攒石期间同步刷材料至关重要：卡池 21 天，每天 180 树脂（自然+4条脆弱），约 3780 树脂，可以覆盖 BOSS + 天赋 + 武器的核心部分。

## 四、攒石期间同步养成规划策略

### 4.1 优先级排序

1. **特产采集**：不消耗树脂，每天顺手采，约 3-4 天可集齐 168 个
2. **普通敌人掉落**：不消耗树脂，可配合探索时顺路刷
3. **天赋书 + 武器材料**：按日轮换，提前查好哪天刷什么，不浪费树脂
4. **普通 BOSS**：40 树脂/次，穿插在天赋/武器本的间隙刷
5. **周本**：每周打 3 个半价周本，优先打目标角色需要的
6. **经验书 + 摩拉**：树脂有剩余时刷地脉之花，或用参量质变仪
7. **圣遗物**：最后考虑，运气成分大，先保证角色可用（4星过渡套即可）

### 4.2 与原石任务的协同

| 原石任务类型 | 可同步进行的养成活动 |
|-------------|-------------------|
| 探索宝箱/神瞳 | 顺路采集特产、刷普通敌人掉落 |
| 世界任务 | 任务区域通常有特产和敌人 |
| 每日委托 | 委托区域顺路采集 |
| 深境螺旋 | 不消耗树脂，可用现有角色打，练度不够则跳过 |
| 活动期间 | 活动通常给经验书/摩拉奖励，可减少地脉之花次数 |

### 4.3 日轮换提醒逻辑

网站根据当期 UP 角色的材料需求，自动生成"今天该刷什么"提示：

1. 读取角色材料数据，确定需要的天赋书系列和武器材料系列
2. 根据当前星期几，匹配可刷的秘境
3. 如当天天赋本和武器本都可用，提示玩家二选一（建议优先天赋，因为周本掉落可转换）
4. 如当天不可刷，提示"今天无目标天赋本/武器本，建议刷 BOSS/地脉/探索"
